# Plugged Dream — Português (Brasil)

Community translation for `plugged_dream` version `v1.3.0`.

Only the 23 translated Lua files under the mod's `scripts/` directory are included. Every file is tied to the SHA-256 hash of its original counterpart, so the launcher refuses to apply the package to a different or modified game version.

Run `build.ps1` from PowerShell to recreate the `.kllang` package.
