# Kristal Engine — Russian

This patch adapts the community project [kristal_rus](https://github.com/neofarsh/kristal_rus) to the Kristal Launcher staged-patch format. It installs the original Russian fonts, interface sprites, translated character/spell data, and runtime text hooks without modifying the user's original game package.

The upstream translation is incomplete by design. Its published status reports complete sprites, characters, and spells; approximately 90% font coverage; approximately 70% interface coverage; and no item or equipment translation. Compatibility with English text is also not guaranteed by the upstream project.
